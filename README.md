# FreeCAD-Projects

Параметричні FPV-рами (Python + build123d, з експортом у FreeCAD) і кілька корпусів, зроблених у FreeCAD вручну.

Кожна рама — окремий Python-проєкт із перевірками, тестами і готовими файлами:
DXF/STEP для різки карбону, STL/3MF для друку, `.FCStd` для FreeCAD. Деталі — у README кожної папки.

## Інші проєкти (FreeCAD)

Корпуси й тримачі, змодельовані у FreeCAD вручну; рендерів для них немає.

| Папка | Що всередині |
|---|---|
| [ENTEL](ENTEL/) | `ENTEL.FCStd`, плити у STL/3MF |
| [ESP32-PrinterCamera](ESP32-PrinterCamera/) | корпус камери ESP32 для принтера, STL |
| [Raspberry-Pi-Zero-Webcam](Raspberry-Pi-Zero-Webcam/) | корпус вебкамери на Pi Zero, деталі у 3MF |
| [PDB-Cover](PDB-Cover/) | кришка плати розподілу живлення |
| [Ubiquity-Holders](Ubiquity-Holders/) | тримачі |
| [Scratch](Scratch/) | чернетки |

## Як перебудувати раму

Приклад для Bolid; назва команди кожної рами — у `[project.scripts]` її `pyproject.toml`.

```
cd Bolid-5inch
uv sync
uv run bolid check
uv run pytest
xvfb-run -a uv run bolid render
```
