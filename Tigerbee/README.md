# Tigerbee 5" — фрістайл у стилі Tiger Beetle

П'ятидюймовий фрістайл, що бере у твоєї Tiger Beetle її обличчя — вушка й горбик на носі, «копитця» на хвості, деку з вилкою під камеру й шевронами, ромб за мотором — і виправляє те, що в ній погано. Ця папка раніше містила одну зі старих спроб відтворити Tiger Beetle; тепер тут нова рама з нуля (стара — в історії git, сама рама відтворена в [Tigerbeetle-7inch](../Tigerbeetle-7inch)).

![Зібрана рама](exports/renders/hero.png)

> **Стан.** CAD-модель на тому ж рушії, що й решта рам репозиторію: усі геометричні перевірки й тести проходять,
> промінь порахований балковою моделлю і FEA. Нічого не вирізали, не друкували й не літали.

Усі картинки — у [галереї](exports/GALLERY.md).

## 1. Від Tiger Beetle — і що виправлено

Взято від твоєї рами: ніс із двома вушками й горбиком, хвіст на двох «копитцях», довга дека з вилкою під камеру
й шевронами вздовж, ромб на кінці променя за мотором.

| | Tiger Beetle | Тут |
|---|---|---|
| Схема | передні й задні промені Tiger Beetle стоять під різними кутами (33° і 40°) | однаковий кут спереду й ззаду, широкий X |
| Підлога | дві пластини, що перекриваються лише частково | сендвіч на всю довжину: дві обшивки, промені й ободи між ними |
| Промені | 5 мм, ширина «на око» | 6 мм, ширина за епюрою моменту; та сама маса, удвічі більше навантаження |
| Стійки | двох довжин на двох рівнях | 8 однакових на одній палубі |

## 2. Промінь: розрахунок

Балкова модель (`zhalo.structure`), вільна частина променя, мотор із гвинтом на кінці:

| Варіант | Маса, г | Сила до руйнування верт. / бічна, Н | Частота, Гц |
|---|---|---|---|
| 5 мм, 15→11, болт на 30 (як Zhalo) | 3,5 | 673 / 2019 | 312 |
| 6 мм, 16→10,5, болт на 36 (як Strila) | 3,7 | 1177 / 3091 | 507 |
| **6 мм, 18→11, болт на 40 (обрано)** | 3,5 | 1442 / 3804 | 608 |

Обраний промінь у 3D-FEA (ортотропний карбон 0/90, затиснутий під ногами обшивок):

| | |
|---|---|
| Вертикальна сила до 600 МПа | **1195 Н** |
| Бічна сила до 600 МПа | **3130 Н** |
| Жорсткість верт. / бічна | 412 / 1711 Н/мм |
| Перша власна частота | **457 Гц** (≈ 27 400 об/хв) |
| Маса променя | 18,9 г |

![Напруження](exports/analysis/stress_vertical.png)



Балкова модель завищує частоту приблизно на 15 % (не бачить податливості затиску), тож абсолютні числа — з FEA.
600 МПа — обережна межа для тканини 0/90 **уздовж волокон**: промені різати вздовж волокон.

## 5. Код

```bash
uv sync
uv run python -m tigerbee check     # усі перевірки
uv run python -m tigerbee analyse   # балкова модель + FEA (потрібна libGLU)
uv run python -m tigerbee all       # exports/: DXF, STEP, STL, 3MF, FreeCAD, рендери, галерея
uv run pytest
```

Стиль Tiger Beetle (контури підлоги, деки, променя) — спільний модуль рушія `zhalo/tiger.py`; аксесуари сімейства —
`zhalo/accessories/tiger_*.py`. Розміри цієї рами — у `src/tigerbee/__init__.py`.

## Що не перевірено

- Нічого не виготовлено; посадки TPU взяті з правил, що працюють на інших рамах репозиторію.
- FEA рахує один промінь, жорстко затиснутий; реальна частота буде трохи нижчою.
- Розміри обладнання (стек, передавач, камера, батарея) — типові оболонки, а не конкретні моделі.
