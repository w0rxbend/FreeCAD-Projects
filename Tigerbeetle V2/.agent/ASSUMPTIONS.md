# Assumptions requiring evidence

| Item | Confidence | Verification |
| --- | --- | --- |
| Scans represent separate flat carbon parts | medium | independent analysts |
| Drawings are approximately orthographic | medium | anchor residuals / scan metadata |
| Hole grids may use FPV stack/motor standards | low | independent standards reviewer and physical anchor |
| Absolute scale | unknown | identified measured length or unambiguous independent anchors |
| Part thickness, standoff height, vertical order | unknown | physical dimensions / assembled reference |

Unknown dimensions must not become manufacturing defaults silently.
